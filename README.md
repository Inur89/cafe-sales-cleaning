# Café Sales Data Cleaning

A project involving data cleaning and quality assessment was built using Python and Pandas. The project used a deliberately "dirty" café transactions dataset.

## Overview

The raw dataset (`dirty_cafe_sales.csv`) contains 10,000 café transactions with a range of common real-world data quality issues: missing values, placeholder strings (`ERROR`, `UNKNOWN`), inconsistent text formatting, wrong data types, and invalid dates. This project profiles the data, cleans it systematically, and validates the result — producing an analysis-ready dataset.

## Dataset

| Column | Description |
|---|---|
| Transaction ID | Unique identifier per transaction |
| Item | Product purchased (e.g. Coffee, Cake, Juice) |
| Quantity | Units purchased |
| Price Per Unit | Price per unit (€) |
| Total Spent | Total transaction value (€) |
| Payment Method | e.g. Digital Wallet, Cash, Credit Card |
| Location | Takeaway or In-store |
| Transaction Date | Date of purchase |

## Data Quality Issues Identified

- Missing values across every column (Payment Method and Location most affected)
- `"ERROR"` and `"UNKNOWN"` used as placeholder strings instead of true nulls
- Leading/trailing whitespace in text fields (Item, Payment Method, Location)
- Numeric columns (`Quantity`, `Price Per Unit`) stored as text
- Inconsistent/invalid date formats in `Transaction Date`
- Duplicate record check

## Cleaning Process

1. **Load & profile** – import the raw CSV, inspect structure with `.info()` and `.describe()`
2. **Standardize text** – strip whitespace from `Item`, `Payment Method`, `Location`
3. **Visualize missingness (before)** – bar chart of missing/placeholder values per column
4. **Check duplicates**
5. **Normalize placeholders** – replace `"ERROR"` and `"UNKNOWN"` with `NaN`
6. **Drop invalid rows** – remove records with no `Item` (cannot be reliably imputed)
7. **Fix dates** – parse `Transaction Date` to datetime, drop unparseable dates, normalize year
8. **Impute Quantity** – convert to numeric, fill missing values with the median *per Item*
9. **Impute Price Per Unit** – convert to numeric, fill with median *per Item*, then overall median as fallback
10. **Impute categorical fields** – fill `Payment Method` and `Location` with their mode
11. **Recalculate Total Spent** – derived as `Quantity × Price Per Unit` for consistency
12. **Validate** – confirm zero remaining missing values
13. **Export** – save the cleaned dataset to `cleaned_cafe_sales.csv`
